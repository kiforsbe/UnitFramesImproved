# UnitFramesImproved
Extends the Blizzard unitframes for better visuals, with a minimal-ish footprint

## Changes from Version 2
- UnitFramesImproved now supports Classic Era, Classic (progression) and Retail in one universal package.

## Supported Clients
- Retail / Midnight (`UnitFramesImproved.toc`)
- Classic Era / Vanilla (`UnitFramesImproved_Vanilla.toc`)
- Classic progression - currently Mists of Pandaria Classic, and any future Classic expansion covered by the same file (`UnitFramesImproved_Classic.toc`)

## Known Issues
### Classic Era & Classic progression
- The functionality to scale the frames has not been re-implemented (yet?)
- The functionality to anchor the frames to each other has not been re-implemented (yet?)

## Distribution
Packaged and distributed via CurseForge
